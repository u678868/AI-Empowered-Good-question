# 架构与目录规范

## 1. 目标

明确项目分区、模块职责与协作边界，确保与 `AGENTS.md` 一致，并保证 `README.md` 状态表与代码实际进度同步。

## 2. 目录分区

| 分区 | 目录 / 文件 | 权限 | 说明 |
| :--- | :--- | :--- | :--- |

| 模块 | 计划路径 | 状态 |

## 4. 开发约定

- 严禁虚构功能：未完成项必须标注为 `⏳ 未实现` 或 `[wip] 开发中`。
